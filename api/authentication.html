API

Authentication Draft

Server access uses bearer JWTs carrying issuer, audience and tenant claims; session access uses the dashboard's authenticated session. Tokens are scoped, expiring and rotatable.

POST/api/v1/auth/login
{
  "email": "user@example.com",
  "password": "secret"
}

The design contract returns an access token, a refresh token, the token type, expiry, the user record and the caller's permission set (for example dashboard:read, transactions:read). Login failures return 401; a locked account returns 423; excessive attempts return 429.
