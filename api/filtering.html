Filtering

Filtering narrows a collection before pagination and sorting. Use the exact parameter names and value formats published for each route; filters are a query aid, never a substitute for authorization or tenant isolation.

Filter behavior

RuleClient guidance
Tenant scopeEvery result is constrained by the authenticated tenant even when no tenant filter is supplied.
Unknown parametersDo not depend on ignored parameters. Remove them unless the route contract accepts them.
Exact valuesUse canonical ids, ISO-8601 timestamps, documented enum values and exact currency codes.
RangesConfirm whether boundaries are inclusive and use UTC for time ranges.
Empty filtersExpect a bounded default page rather than an unbounded export.

Filters on GET /discrepancies

ParameterAccepted values
statusneeds_review, assigned, resolved, open, closed, pending, missing_payment, missing_transaction, amount_mismatch, duplicate. Matches the discrepancy's anomaly type or status.
severitycritical, warning, info
resolvedopen or resolved
qText of up to 200 characters, matched against the transaction id and anomaly type.
tenantOptional; must equal your own tenant, otherwise 403 tenant_access_denied.

An unsupported value returns 400 invalid_parameter (for example, Unsupported status filter.). Unknown parameters are ignored, so a misspelled filter silently returns unfiltered results.

Planned. Filtering by provider, and date-range filters such as created_from and created_to, have no implementation on this route today.

Example query

curl --get "$PESAGUARD_API_URL/discrepancies" \
  --data-urlencode "status=missing_payment" \
  --data-urlencode "severity=critical" \
  --data-urlencode "page=1" \
  --data-urlencode "per_page=50" \
  -H "Authorization: Bearer $PESAGUARD_ACCESS_TOKEN"

Safe filtering workflow

  1. Start with one filter and a small per_page.
  2. Confirm response metadata and tenant context.
  3. Add one filter at a time and record the resulting count.
  4. Use pagination and stable sorting for exports or reconciliation jobs.
