Versioning Live

All public routes belong under a versioned namespace — /api/v1 — unless a documented compatibility alias exists.

  • A version remains supported for at least 90 days after a deprecation notice is published.
  • Breaking changes require a new versioned route prefix — never a silent shape change in place.
  • Deprecations are announced in release notes and in the OpenAPI specification itself.
