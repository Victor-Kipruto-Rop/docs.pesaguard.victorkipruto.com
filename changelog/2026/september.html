Changelog

September 2026

The September release establishes the public documentation baseline for PesaGuard API consumers. The entries below describe documentation and contract visibility; they do not claim an unverified runtime feature release.

Documentation and platform guidance

DOCUMENTATION · API

Expanded API integration guidance

Added detailed guidance for authentication, request validation, filtering, sorting, pagination, rate limits, idempotency, errors, versioning and OpenAPI contract review.

Impact: No endpoint behavior is implied by the documentation update. Integrators should use the running deployment's OpenAPI document as the authority.

SECURITY · GUIDANCE

Credential lifecycle documented

Documented API-key ownership, environment separation, rotation, revocation, tenant context, service accounts, audit events and compromise response.

Action: Review production credentials for owner, scope, expiry and rotation evidence.

COMPATIBILITY · POLICY

Version migration guidance clarified

Breaking changes must use a versioned route and receive at least 90 days of support after notice. Clients should compare contracts and test errors, retries and reconciliation semantics.

Consumer action list

  1. Fetch and pin the OpenAPI document for the environment being integrated.
  2. Confirm the credential type, tenant membership, scopes and expiry.
  3. Implement bounded retries with idempotency for writes.
  4. Handle 401, 403, 409, 429 and 5xx responses explicitly.
  5. Record request ids and validate reconciliation outcomes in staging before production rollout.

Scope of this release record

This entry records the documentation work completed in September. It is not a substitute for a deployment release note, incident report or runtime feature flag. When the implementation and documentation differ, pause adoption and verify the running contract with the service owner.
