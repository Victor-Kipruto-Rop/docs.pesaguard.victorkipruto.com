Errors

401 · Authentication

The server could not establish a valid identity for the request. The credential may be missing, malformed, expired, revoked, issued for another audience or sent to the wrong environment.

See API · Errors for the envelope and client behaviour.

Common causes

  • No Authorization header was sent.
  • The scheme is not Bearer or the token contains extra whitespace.
  • The token is expired, revoked, signed by an unknown issuer or intended for another audience.
  • A sandbox credential was sent to production or the reverse.

Recovery procedure

  1. Confirm the base URL and environment.
  2. Check the header without logging the secret.
  3. Renew or replace the credential once.
  4. Retry the original request only after authentication succeeds.
  5. Escalate repeated failures with the request id and token metadata, never the raw token.

Example

HTTP/1.1 401 Unauthorized
  WWW-Authenticate: Bearer
  Content-Type: application/json

  {"error":{"code":"AUTHENTICATION_FAILED","message":"Credentials were rejected.","request_id":"request_01J..."}}
