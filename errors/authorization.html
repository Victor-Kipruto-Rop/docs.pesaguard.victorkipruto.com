Errors

403 · Authorization

The server recognized the caller but policy denied the requested operation. The usual causes are insufficient scope, missing role, inactive membership or an attempt to access a resource outside the authenticated tenant.

See API · Errors for the envelope and client behaviour.

401 versus 403

StatusMeaningFix
401No valid identity was established.Renew or replace the credential.
403Identity is valid but policy denies access.Check scope, role and tenant membership.

Developer checklist

  • Confirm the principal belongs to the target organization.
  • Check the route's required scope and the credential's granted scopes.
  • Do not accept a client-supplied tenant id without server membership validation.
  • Do not retry unchanged requests; permission will not appear through repetition.
  • Record the request id for an operator authorization review.
