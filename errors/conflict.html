Errors

409 · Conflict

The request is valid but cannot be applied to the current resource state. In write paths, this commonly means an idempotency key or provider reference already represents an existing operation.

See API · Errors for the envelope and client behaviour.

Conflict categories

CategoryExampleCorrect response
Duplicate operationSame idempotency key with the same or completed request.Retrieve or return the original outcome.
Key mismatchSame key reused with a different request body.Stop and create a new logical operation.
State conflictAttempt to resolve an already resolved record.Read current state and preserve history.

Safe recovery

  1. Preserve the response body and request id.
  2. Read the resource using the same tenant and authorization context.
  3. Compare the server outcome with the intended operation.
  4. Never create a second record merely because the first response was lost.
  5. Escalate ambiguous financial state for reconciliation review.
