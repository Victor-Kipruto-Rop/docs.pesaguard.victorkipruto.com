Errors

404 · Not found

The requested resource is not available within the caller's authorized tenant scope. The response intentionally does not reveal whether an identifier exists in another organization.

See API · Errors for the envelope and client behaviour.

What to check

  • Use the correct environment base URL and versioned route.
  • Check path parameter spelling, encoding and resource id format.
  • Confirm the resource was created successfully before retrieving it.
  • Confirm the credential belongs to the tenant that owns the resource.
  • Do not probe other tenant ids to distinguish absence from isolation.

Read-after-write behavior

A successful asynchronous write may not be immediately visible in every read model. Follow the documented status or webhook flow, use bounded polling and preserve the original request id rather than issuing unbounded reads.
