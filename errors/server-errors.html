Errors

5xx · Server errors

A service, dependency or gateway could not complete the request. Treat the outcome as uncertain for writes: retry with the same idempotency key, then reconcile instead of creating a second operation.

See API · Errors for the envelope and client behaviour.

Failure classes

StatusLikely boundaryClient action
500Unhandled application failure.Bounded retry; escalate repeated request ids.
502Gateway or upstream response invalid.Retry with backoff and check dependency health.
503Service unavailable or overloaded.Reduce load and honor retry guidance.
504Gateway timeout.Assume uncertain write outcome and query safely.

Recovery sequence

  1. Capture status, request id, timestamp, route and environment.
  2. Wait using bounded exponential backoff with jitter.
  3. Retry reads only when safe; retry writes with the same idempotency key.
  4. Check the resulting resource or reconciliation record.
  5. Escalate a persistent failure with correlated logs and metrics.
