Authentication guides

Bearer tokens

Send the access token in the HTTP Authorization header. The service validates its issuer, audience, expiry, tenant context and granted scopes before route authorization.

Every protected request

Authentication establishes identity; authorization then decides whether that identity may use the requested resource.

ISSUERAUDIENCEEXPIRY

Request pattern

curl --fail-with-body "$PESAGUARD_API_URL/api/v1/tenant/current" \
  -H "Authorization: Bearer $PESAGUARD_ACCESS_TOKEN" \
  -H "Accept: application/json"

Token checks

CheckFailure
Signature and issuerReject if token was not issued by the configured authority.
Audience and expiryReject tokens for another API or past their expiration.
Tenant and scopeAuthenticate successfully but return 403 when policy denies access.

When a token is rejected

  1. Check environment and header format.
  2. Renew or replace once.
  3. Preserve the request id if the failure remains.
  4. Never log or send the raw token to support.
