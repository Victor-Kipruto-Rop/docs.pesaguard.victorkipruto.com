Authentication guides

Authentication guides

Set up and operate credentials without confusing identity, tenant access and permissions. These guides cover the supported bearer model, API keys and the current OAuth boundary.

Credential path

Issue the smallest credential, send it correctly, rotate it deliberately and know what a failure means.

ISSUEUSEROTATE
PageFocus
API keysScopes, expiry, rotation metadata, and one credential per integration.
Bearer tokensThe Authorization header, tenant claims, and what a rejected token returns.
OAuthNot supported today. Service access uses scoped bearer tokens issued per deployment.
Key rotationRotate on a schedule and on suspicion; revocation takes effect immediately.

Recommended sequence

  1. Review credential provisioning and tenant scope.
  2. Use bearer tokens or API keys according to the integration type.
  3. Test an authenticated read in staging.
  4. Follow rotation before production rollout.
  5. Do not implement OAuth based on assumptions; see the support boundary.
