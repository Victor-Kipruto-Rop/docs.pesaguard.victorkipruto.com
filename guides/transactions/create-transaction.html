Transaction guides

Create a transaction

Create a transaction only after confirming the running deployment's OpenAPI schema, authentication scope and idempotency contract. A write must be safe to retry and traceable to its source.

Safe write pattern

Validate locally, send one logical operation with one idempotency key, then reconcile the durable outcome.

VALIDATEWRITE ONCERECONCILE

Request checklist

  • Use the correct environment and tenant credential.
  • Send exact amount, currency, reference and timestamp formats.
  • Generate and persist an idempotency key for the logical operation.
  • Set a client timeout without assuming timeout means rejection.

Write sequence

  1. Validate the payload against the deployment contract.
  2. Send the authenticated request.
  3. Persist the response or request id.
  4. On uncertainty, retry with the same key.
  5. Retrieve and reconcile the resulting transaction.

The write path is documented in the OpenAPI contract — confirm the schema against your deployment.
