Retrieve a transaction

Retrieve one transaction by its M-Pesa transaction id within a tenant. The response carries the recorded M-Pesa fields, the raw callback payload and, when one can be found, a matching internal ledger record.

Read pattern

GET/api/v1/customers/{tenant_id}/transactions/{trans_id}
GET /api/v1/customers/{tenant_id}/transactions/{trans_id}
Authorization: Bearer <token>
Accept: application/json

Requires the read:discrepancies permission. tenant_id must be the caller's tenant unless the caller holds manage:all_tenants. The route is also registered as /v1/customers/{tenant_id}/transactions/{trans_id}; use the /api/v1 form.

Response fields

FieldMeaning
tenant_id, trans_idThe tenant and the M-Pesa transaction id you asked for.
trans_amount, msisdn, business_short_code, trans_timeThe recorded M-Pesa values; trans_time is stored as received.
created_atWhen PesaGuard recorded the transaction, as an ISO 8601 timestamp.
raw_payloadThe stored callback payload.
matched_recordnull, or the most recent internal record with the same phone number and an amount within 0.01 (internal_ref, amount, phone_number, status, synced_at). Treat it as a hint, not the reconciliation result.

Errors

StatuserrorMeaning
404not_foundNo transaction with that trans_id exists for the tenant.
403tenant_access_deniedThe tenant in the path is not yours. This is checked before any lookup, so a 404 cannot be used to probe another organization.
500fetch_failedThe lookup failed on the server; retry with backoff.
