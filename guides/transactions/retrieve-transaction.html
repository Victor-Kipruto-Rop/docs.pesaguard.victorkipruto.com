Transaction guides

Retrieve a transaction

Retrieve a transaction by its server-issued identifier within the authenticated tenant. Resource ids are not globally trusted and a not-found response must not be used to probe another organization.

Read pattern

GET /api/v1/transactions/{transaction_id}
  Authorization: Bearer <token>
  Accept: application/json

Interpret the response

CheckWhy
TenantConfirm the response belongs to the expected organization.
StateUse lifecycle state rather than assuming creation means settlement.
EvidenceRead provider reference, match result and audit correlation.

When it returns 404

Check the environment, route version, id format and authenticated tenant. For asynchronous writes, use bounded polling or webhook delivery rather than an unbounded read loop.

Detail lookups always include tenant predicates; IDs are not globally trusted.
