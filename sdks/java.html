Java

Generate a Java client from the deployment's OpenAPI document, then wrap it with explicit timeouts, authentication, error mapping and idempotent write handling.

Generate a Java client

curl --fail "$PESAGUARD_API_URL/openapi.json" -o openapi.json
java -jar openapi-generator-cli.jar generate \
  -i openapi.json -g java -o ./generated/pesaguard \
  --library okhttp-gson

Client configuration

ApiClient client = new ApiClient();
client.setBasePath(System.getenv("PESAGUARD_API_URL"));
client.setApiKey(System.getenv("PESAGUARD_ACCESS_TOKEN"));
client.setConnectTimeout(10_000);
client.setReadTimeout(10_000);
