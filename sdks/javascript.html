JavaScript

Use the platform fetch API or a generated client from OpenAPI. Keep the HTTP boundary server-side, centralize authentication and make write retries idempotent.

Minimal client boundary

async function getTenant(baseUrl, token) {
  const response = await fetch(`${baseUrl}/api/v1/tenant/current`, {
    headers: { Authorization: `Bearer ${token}`, Accept: "application/json" },
    signal: AbortSignal.timeout(10000)
  });
  const body = await response.json();
  if (!response.ok) throw new Error(`${body.error?.code ?? "HTTP_ERROR"} (${response.status})`);
  return body;
}

Production client rules

  • Inject tokens from a server-side secret boundary, never browser bundles.
  • Use one timeout policy and bounded retry policy for all calls.
  • Retry writes only with the same idempotency key.
  • Preserve response request ids in structured logs.
  • Handle 401, 403, 409, 429 and 5xx separately.

Generated JavaScript clients

Inspect generated fetch configuration, serialization of dates and amounts, pagination helpers and error types. Add a thin adapter so the rest of the application does not depend on generator-specific classes.
