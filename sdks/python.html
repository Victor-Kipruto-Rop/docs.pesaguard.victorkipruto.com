Python

Use a small requests-based adapter or generate a client from OpenAPI. Python workers should make timeouts, retries, idempotency and tenant context explicit.

Authenticated read

import os
  import requests

  response = requests.get(
    f"{os.environ['PESAGUARD_API_URL']}/api/v1/tenant/current",
    headers={"Authorization": f"Bearer {os.environ['PESAGUARD_ACCESS_TOKEN']}"},
    timeout=10,
  )
  response.raise_for_status()

Retry boundary

from requests.adapters import HTTPAdapter
  from urllib3.util.retry import Retry

  retry = Retry(total=3, backoff_factor=0.5, status_forcelist=[429, 502, 503, 504], allowed_methods=["GET"])
  session = requests.Session()
  session.mount("https://", HTTPAdapter(max_retries=retry))

Restrict automatic retries to safe reads unless the write uses a stable idempotency key and the application can reconcile an uncertain outcome.

Worker checklist

  • Use one session policy for timeouts and TLS verification.
  • Keep credentials out of job payloads and logs.
  • Record request and transaction ids.
  • Use UTC-aware timestamps and exact decimal handling for money.
  • Bound pagination and worker concurrency.
