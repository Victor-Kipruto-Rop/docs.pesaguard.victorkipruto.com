TypeScript

Generate typed models from the OpenAPI document, then keep runtime validation and error handling at the client boundary. Compile-time types reduce mistakes but cannot validate untrusted responses by themselves.

Generate a client

curl --fail "$PESAGUARD_API_URL/openapi.json" -o openapi.json
npx @openapitools/openapi-generator-cli generate \
  -i openapi.json -g typescript-fetch -o ./generated/pesaguard

Typed request wrapper

type PesaGuardConfig = {
  baseUrl: string;
  token: string;
};

export async function getTenant(config: PesaGuardConfig) {
  const response = await fetch(`${config.baseUrl}/api/v1/tenant/current`, {
    headers: { Authorization: `Bearer ${config.token}` }
  });
  if (!response.ok) throw new Error(`PesaGuard HTTP ${response.status}`);
  return response.json();
}

Type safety checklist

  • Pin the OpenAPI document used for generation.
  • Regenerate in CI and review the diff.
  • Validate dates, amounts and enum values at runtime.
  • Model unknown response fields as forward-compatible.
  • Keep generated code separate from business logic.
