Security

Responsible disclosure Draft

If you believe you have found a security issue, tell us privately and we will treat it seriously: acknowledge, reproduce, fix, and credit you if you want.

  1. Open a private security advisory or issue on the source repository — do not include exploit details in a public issue.
  2. Include reproduction steps and the request id or timestamp if the issue involves API behaviour.
  3. We acknowledge receipt, then confirm or decline with reasoning.
  4. Fixes are released with a note; you may be credited unless you prefer otherwise.
