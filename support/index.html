Support

Support Draft

PesaGuard is deployed and supported with the pilot team. There is no ticket portal yet — the fastest paths are the source repository and the pilot conversation.

  • Documentation feedback — open an issue on the source repository.
  • Production issues — quote the request_id from the error response; it is the correlation key operators search for.
  • Security issues — follow responsible disclosure; use private advisories, not public issues.
  • Status questions — check status first; incidents carry scope and duration.
