Testing

Testing against staging

Staging is the realistic safety boundary for integration work: same service behavior, separate data stores, credentials, brokers and operational risk.

Production rehearsal, isolated

Exercise the workflows production will see without sharing production secrets, tenants, topics or financial data.

ISOLATEDREALREPEATABLE

Staging preparation

  • Create or select a staging-only tenant.
  • Use staging API keys with short expiry and least privilege.
  • Confirm database, Redis and Kafka endpoints are staging-specific.
  • Mark all synthetic transactions and provider references as test data.
  • Validate the merged configuration quietly before startup.
