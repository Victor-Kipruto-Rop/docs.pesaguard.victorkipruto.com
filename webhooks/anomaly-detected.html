Webhooks

anomaly.detected

A named rule or statistical check flagged the transaction for human review.

Payload fields are still being stabilized; subscribe to the OpenAPI document rather than hard-coding shapes.

Consumer behavior

Use this event to create or update a review task. Display the signal name, severity, evidence window and transaction context; do not label the transaction as confirmed fraud automatically.

Assertions

  • Signature is valid before parsing.
  • Event id is deduplicated.
  • Tenant and transaction context are authorized.
  • Reviewer action is recorded separately in the audit trail.
