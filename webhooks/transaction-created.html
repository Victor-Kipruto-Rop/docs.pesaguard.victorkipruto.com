Webhooks

transaction.created

A payment event was accepted and validated, and is now a PesaGuard record.

Payload fields are still being stabilized; subscribe to the OpenAPI document rather than hard-coding shapes.

Consumer behavior

Use this event to begin a read or workflow projection. Creation proves the event was accepted and validated; it does not prove matching, settlement or final reconciliation.

Assertions

  • Transaction id and event id are retained.
  • Duplicate delivery creates no duplicate projection.
  • Consumers follow later state and reconciliation events.
